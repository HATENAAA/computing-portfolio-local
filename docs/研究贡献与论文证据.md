# 毕业论文研究工作

《基于深度学习的遥感影像超分辨率重建》，2025年10月—2026年5月。

复现MCArb框架（Zhang et al., IEEE TGRS 2025），以MCNet／SSPSR／ERCSR为主干，加入3DMetaUM、SAFAM和3DSPPM模块。MATLAB完成Pavia Centre与Chikusei预处理；Python流程逐图计算PSNR、SSIM、CC、RMSE、SAM和ERGAS，再按图像数平均，输出重建图和误差图。

在Pavia Centre的×4／×8下，三类模型的PSNR、SSIM、CC均优于对应基线；MCArb-SSPSR在两数据集和两个尺度六指标均改善（相较SSPSR-b，PSNR提升0.21–0.36 dB）。将三维上采样换为二维模块使ERCSR PSNR分别下降1.31／0.42 dB；×2辅助上采样与25%裁剪面积比例取得均衡结果，与原文一致。

最终代码、图像与SHA-256清单见hsi-sr-lab/thesis-final。论文先逐图计算指标，再按图像数求平均。独立工作台还支持按场景等权汇总。
