# 王嘉玮 · 本地作品集 | Jiawei Wang · Local Portfolio

八个可在本机运行的项目，包含源代码、示例数据与启动脚本。浏览器可直接查看[静态作品集](https://hatenaaa.github.io/computing-portfolio-local/)，含中英文案例、交互演示和实验结果。

## 本地运行

1. 从仓库下载 ZIP 或克隆仓库。准备 Python 3.12、Node.js 22.13 或更新版本、JDK 17 或更新版本，以及 Maven。
2. 首次运行双击 `安装全部依赖.command`。
3. 双击 `启动完整作品集.command`，在首页选择应用。也可用 `启动作品.command` 单独启动项目。

These launchers are for macOS. See the [English setup guide](projects/guide-en.html) for instructions and sample accounts.
