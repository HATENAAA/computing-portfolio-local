# 制造订单与库存管理系统

全栈系统开发。技术栈为 Vue、Spring Boot、MyBatis 和 MySQL。

结合订单专属BOM快照、有序行锁与整单事务，保持物料需求稳定，并在库存不足时回滚预留。

在同一事务内核对库存余额、流水记录与有效预留；使用请求ID实现幂等收货。MySQL 部署测试验证了并发超卖防护、缺料回滚及库存流水一致性。

本地演示基于预置的虚构工厂数据，可查看库存余额、收发流水与有效预留。使用作品集启动器启动后，选择演示工厂登录，在「物料与 BOM」运行库存对账，或从某一物料跳到对应收发流水。

根目录运行“启动完整作品集.command”，或通过“启动作品.command”单独启动。应用地址：http://127.0.0.1:8081/。
