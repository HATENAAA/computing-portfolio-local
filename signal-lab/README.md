# 虚拟仪器与信号分析系统

双击仓库根目录的 `Launch Project.command`，选择「5 Signal Analysis」。工作台会在浏览器中打开，首次进入自动计算双频信号通过低通滤波器后的波形和频谱。

- **双频滤波**用 50 Hz 和 200 Hz 的混合输入检查 100 Hz 低通滤波器。调节截止频率后，点击「应用参数并计算」比较两处增益。
- **采样混叠**在 1024 Hz 采样率下观察 750 Hz 正弦信号的折叠频率。
- **测量系统频响**以固定种子的白噪声激励已知滤波器，用 Welch H1 估计输入与输出之间的增益、相位和相干性。
- **分析实录波形**直接载入随附的 MIT-BIH 记录 100、MLII 导联前 10 秒，采样率为 360 Hz。输入是原记录，输出是工作台计算的滤波结果。[PhysioNet 数据与许可](https://physionet.org/content/mitdb/1.0.0/)
- **导入 CSV**接受 128 至 32768 行等间隔数据，首行为 time_s,input。若有 filtered 列则保留原输出。选择文件后自动分析，可再修改参数重新计算。

时域和 X–Y 视图使用同一对输入／输出。报告包含分析参数、波形来源指纹与测量结果，CSV 保存完整采样序列。原始 LabVIEW 工程位于 original/Virtual_Oscilloscope.vi，浏览器工作台使用 Python 数值计算。
