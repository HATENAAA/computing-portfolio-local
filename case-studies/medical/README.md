# 熙心健康体检预约与报告系统

暑期实训团队项目，评为优秀项目。个人分工为前端制作、素材查找与内容整合。

完整本地系统由当前目录的 Vue 用户端和 `medical-platform/backend` 的 Spring Boot 后端组成。双击根目录的「启动作品.command」，输入 9，可打开服务。用户端和医生端均可使用页面上的示例账号，机构、人员和体检记录均为虚构数据。预约与报告保存在服务端的本地数据库。原团队工程使用 MySQL；本地案例首次启动会初始化演示数据库。

`demo.html` 是可随静态作品集浏览的预约和报告流程。医生端工作台根据实训报告和团队接口补建，支持按手机号、姓名、性别、套餐、体检日期和报告状态筛选，录入并发布检查结果以及查阅已归档报告。用户端可在预约记录中查看待检与已出报告的订单。
