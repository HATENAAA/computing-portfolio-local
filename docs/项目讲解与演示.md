# 项目浏览与演示

首页按技术领域浏览八项项目。

## 基于深度学习的遥感影像超分辨率重建

复现MCArb框架，在三类主干中整合空谱学习模块；开发Python评测流程，以逐图平均的六项指标、重建图和误差图分析多尺度重建结果。

入口：projects/hsi.html

## VRFitAI

将WebXR双控制器交互与桌面／移动端训练流程整合，通过幂等保存和事件重放保持训练记录一致，并将历史表现建议与DeepSeek指导接入应用。

入口：projects/vrfitai.html

## 制造订单与库存管理系统

通过订单专属BOM快照、有序行锁和整单事务保持物料需求与库存预留一致；结合库存流水对账及幂等收货，处理并发订单与重复提交。

入口：projects/manufacturing.html

## 视觉火焰检测与事件分析系统

结合颜色—边缘规则、形态学闭运算和运动线索检测图像及视频中的火焰区域；通过滑动窗口帧投票确认事件。工作台可运行单图模型对照和 32 帧检测框评测。视频事件研究使用时间 IoU。

入口：projects/firewatch.html

## 虚拟仪器与信号分析系统

构建双通道虚拟示波器，整合滤波、FFT与X-Y分析；开发Welch H1频响估计，并以已知理论响应检验噪声、窗长和重叠率的影响。

入口：projects/signal.html

## 上海红色文化地图

浏览已核对的历史场址，按步行路网规划两点或多站路线，查看分段距离与预计用时。

入口：projects/city.html

## 卫星测深回归分析

打开工作台即运行合成样例，按组留出测试集并比较线性回归与 SVR。还可以预测新样本，或单独查看 ICESat-2 光子相对海平面的高度。

入口：projects/bathymetry.html

## 体检预约与报告系统

实训报告记载的个人分工为前端制作、素材查找、内容整合。预约和报告是团队系统的功能，展出的本地医生端工作台根据实训报告与团队接口补建。

入口：projects/medical.html
