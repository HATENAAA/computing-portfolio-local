Run the projects locally

Use the complete project folder containing the source code and launch scripts.

  1. Install Python 3.12, Node.js 22.13 or later, JDK 17 or later, and Maven.
  2. On macOS, open 安装全部依赖.command on your first run to install project dependencies.
  3. Open 启动完整作品集.command to start the local portfolio, then choose an application under Run local projects. To start just one project, use 启动作品.command.

The launcher reuses running services and chooses available ports if a default port is in use. Press Ctrl+C in the launcher terminal to stop services started by that session.

The manufacturing sign-in page offers demo accounts. VRFitAI supports desktop practice and training records before an AI assistant is configured.

Use launcher option 9 to run the Xixin Health Screening system with its patient and doctor demo accounts. The local database stores bookings and published reports.
