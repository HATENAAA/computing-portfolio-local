# 视觉火焰检测与事件分析系统

计算机视觉算法开发。

设计颜色—边缘规则检测火焰，通过形态学闭运算连接碎片化区域；结合局部与场景运动线索及滑动窗口帧投票确认火焰事件。比较Sobel、Canny、Laplacian和Scharr算子。

开发一对一时间IoU匹配及指标报告；在四段按来源分离的标注视频上比较规则检测与ONNX分类（两段验证／两段测试），验证后固定测试设置。

本地工作台还提供 32 张 FURG 标注帧的检测框评测，使用空间 IoU。视频事件评测使用时间 IoU。

根目录运行“启动完整作品集.command”，或通过“启动作品.command”单独启动。应用地址：http://127.0.0.1:8765/。
